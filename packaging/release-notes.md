## Downloads

| System | File | How |
|---|---|---|
| Windows 10/11 | `CS2HighlightMaker-Setup.exe` | Run it, then start *CS2 Highlight Maker* from the Start menu. |
| Windows (no install) | `CS2HighlightMaker-windows-x64-portable.zip` | Unzip anywhere and run `CS2HighlightMaker.exe`. |
| Linux | `CS2HighlightMaker-linux-x86_64.tar.gz` | `tar xzf` it and run `CS2HighlightMaker/CS2HighlightMaker`. Or install from source with `./install.sh`. |

A setup screen opens on first start and checks CS2, Steam, FFmpeg and the recording plugin.
`libserver.so` / `server.dll` are the recording plugin on its own, already included in the downloads above.

> Windows support is new and has not been tested on a Windows PC with CS2 yet. Please open an issue if something goes wrong.
